# 專業新聞女主播動作規格（訓練與驅動參考）

## 1. 頭部動作特徵
- **基準姿態**：正面朝向鏡頭，脊椎與頸部保持挺直，整體穩定度高。
- **語氣微點頭（Micro-nods）**：隨說話重音產生極細微上下點頭（振幅約 1°–3°），節奏平穩自然。
- **輕微側傾（Subtle Tilt）**：在語句轉折處，頭部極輕微向左右傾斜（約 2°–4°）後回正。
- **低頭動作**：約在 00:09.0 處短暫微幅低頭（下巴略微內收約 0.6 秒），隨即抬頭回正。

## 2. 眼部與眉眼動作特徵（待後續 LivePortrait / 眼動模型訓練使用）
- **視線焦點**：絕大部分時間緊盯鏡頭正中央（模擬看提詞機狀態）。
- **微幅掃視（Micro-saccades）**：眼球極細微水平左右移動（閱讀提詞機生理反應），不影響直視感。
- **眨眼頻率（Blinking）**：約每 2 至 3 秒自然眨眼一次（00:00.3、00:02.3、00:04.0、00:05.7、00:07.0、00:09.0），閉眼時間極短、節奏均勻。
- **視線下移**：00:09.0 – 00:09.3 配合低頭與眨眼，視線短暫向下瞥向桌面講稿約 0.5 秒，隨後立刻抬眼鎖定鏡頭。
- **眉眼表情**：說話重音時雙眉極輕微上揚（00:02.6、00:04.6），其餘時間放鬆端莊。
